# 01 — Requirement: SRS ฉบับย่อ

ระบบ: Coffee Shop Ordering — สั่งกาแฟออนไลน์
เป้าหมาย: ลูกค้าเลือกเมนู ใส่ตะกร้า กรอกข้อมูลจัดส่ง และสั่งซื้อได้ใน 3 หน้า

## หน้าหลัก 3 หน้า (Modules)

| # | หน้า | ทำอะไรบ้าง |
|---|---|---|
| 1 | หน้าเลือกเมนู (Menu) | แสดงรายการกาแฟพร้อมราคา เลือกเมนู ความหวาน จำนวนแก้ว กด "ใส่ตะกร้า" |
| 2 | หน้าตะกร้าสินค้า (Cart) | สรุปรายการ แก้ไขจำนวนแก้ว (+ / -) แสดงยอดรวม กด "ไปหน้าจัดส่ง" |
| 3 | หน้าจัดส่ง (Delivery) | กรอกชื่อ เบอร์โทร ที่อยู่ กด "ยืนยันสั่งซื้อ" รับหมายเลขคำสั่งซื้อ |

## Business Rules (BR-01 .. BR-06)

| รหัส | กฎ | รายละเอียด | ประเภท |
|---|---|---|---|
| BR-01 | ยอดสั่งซื้อขั้นต่ำ 100 บาท | ยอดต่ำกว่า 100 → แจ้งเตือน ไม่ให้สั่ง (เท่ากับ 100 ผ่านได้) | Business |
| BR-02 | เบอร์โทรต้องเป็นตัวเลข 10 หลัก | ตัวเลข 0-9 เท่านั้น ขึ้นต้น 0 ห้ามตัวหนังสือ/สัญลักษณ์ | Validation |
| BR-03 | ความหวานเริ่มต้น | ไม่เลือกความหวาน → ตั้ง "หวานปกติ 100%" อัตโนมัติ | Business |
| BR-04 | จำนวนแก้วขั้นต่ำ 1 แก้ว | ห้าม 0 / ติดลบ ทั้งตอนเลือกเมนูและในตะกร้า | Validation |
| BR-05 | ที่อยู่จัดส่งห้ามว่าง | ไม่กรอกที่อยู่ → ไม่ให้ยืนยันสั่งซื้อ | Validation |
| BR-06 | ยอดรวมคำนวณถูกต้อง | ยอด = ผลรวม (ราคา x จำนวน) ทุกรายการ เปลี่ยนตามการแก้ไขตะกร้า | Calculation |

## รายการเมนูและราคา (Master Data)

| รหัส | เมนู | ราคา |
|---|---|---|
| M01 | อเมริกาโน่ | 40 บาท |
| M02 | ลาเต้ | 45 บาท |
| M03 | โมจิ | 50 บาท |
| M04 | มัทฉะลาเต้ | 55 บาท |

## ตัวอย่างการคำนวณยอด (ใช้เป็น Test Data)

- อเมริกาโน่ 40 x 2 = 80 บาท (ไม่ผ่านขั้นต่ำ)
- ลาเต้ 45 x 2 = 90 บาท (ไม่ผ่าน) / 45 x 3 = 135 บาท (ผ่าน)
- โมจิ 50 x 2 = 100 บาท (ผ่านพอดี — boundary)
- มัทฉะลาเต้ 55 x 2 = 110 บาท (ผ่าน)
