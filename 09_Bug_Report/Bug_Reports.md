## BUG-001 — กรอกเบอร์โทรเป็นตัวหนังสือภาษาไทยได้ ระบบไม่แจ้งเตือน และสั่งซื้อสำเร็จ

| รายการ | รายละเอียด |
|---|---|
| Severity | **High** |
| พบที่ Test Case | TC-008 |
| เกี่ยวกับกฎ | BR-02 (เบอร์โทรตัวเลข 10 หลัก) |
| Environment | Build 1.0.0 / Chrome |

**Steps to reproduce:**
1. เข้าหน้าเลือกเมนู สั่งลาเต้ 3 แก้ว (135 บาท)
2. ไปหน้ากรอกเบอร์โทร/ที่อยู่จัดส่ง
3. กรอกชื่อ "สมชาย" เบอร์โทร "๐๘๑๒๓๔๕๖๗๘" (เลขไทย) และที่อยู่ครบ
4. กดปุ่มยืนยันสั่งซื้อ

**Actual:** ระบบสั่งซื้อสำเร็จ ไม่มีข้อความแจ้งเตือน เบอร์ดังกล่าวถูกบันทึกลงคำสั่งซื้อ ทำให้ร้านติดต่อลูกค้าไม่ได้

**Expected:** ระบบแจ้งเตือน "เบอร์โทรต้องเป็นตัวเลข 0-9 ครบ 10 หลัก" และไม่ให้กดยืนยันสั่งซื้อจนกว่าจะกรอกถูกต้อง

**Root cause (วิเคราะห์):** หน้าเว็บตรวจเฉพาะ "ความยาว 10 ตัวอักษร" แต่ไม่ได้ตรวจว่าเป็นตัวเลข 0-9 เท่านั้น

## BUG-002 — กดลดจำนวนแก้วเหลือ 0 ระบบคิดเงินยอดติดลบ และสั่งซื้อได้

| รายการ | รายละเอียด |
|---|---|
| Severity | **Critical** |
| พบที่ Test Case | TC-010 |
| เกี่ยวกับกฎ | BR-04 (จำนวนขั้นต่ำ 1 แก้ว) / BR-01 (ขั้นต่ำ 100 บาท) |
| Environment | Build 1.0.0 / Chrome |

**Steps to reproduce:**
1. เข้าหน้าเลือกเมนู ใส่ลาเต้ 1 แก้ว (45 บาท) ลงตะกร้า
2. เข้าหน้าตะกร้า กดปุ่มลดจำนวน (-) 1 ครั้ง จำนวนเหลือ 0
3. กดปุ่มลดอีก 1 ครั้ง จำนวนขึ้นเป็น -1 ยอดรวมแสดง -45 บาท
4. กดไปหน้าจัดส่ง กรอกข้อมูลครบ แล้วกดยืนยันสั่งซื้อ

**Actual:** ยอดรวมเป็น -45 บาท และระบบยังให้ยืนยันสั่งซื้อสำเร็จ (หลุดเงื่อนไขขั้นต่ำ 100 บาท เพราะยอดติดลบ)

**Expected:** ระบบห้ามลดจำนวนต่ำกว่า 1 แก้ว ถ้ากดลบที่ 1 แก้วให้แสดงข้อความยืนยันว่าจะลบรายการออกจากตะกร้าหรือไม่ และยอดรวมต้องไม่ติดลบเด็ดขาด

**Root cause (วิเคราะห์):** ปุ่มลดไม่มีเงื่อนไขกันค่าต่ำสุด (min = 1) และการตรวจขั้นต่ำ 100 บาทใช้เงื่อนไข "ยอด < 100" ซึ่งยอดติดลบผ่านเข้าไปได้
