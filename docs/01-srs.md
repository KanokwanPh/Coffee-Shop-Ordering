# ภาพรวมระบบสั่งกาแฟออนไลน์ (SRS ฉบับย่อ)

ระบบ: Coffee Shop Ordering — สั่งกาแฟออนไลน์
เป้าหมาย: ลูกค้าเลือกเมนู ใส่ตะกร้า กรอกข้อมูลจัดส่ง และสั่งซื้อได้ใน 3 หน้า

## หน้าหลัก 3 หน้า

### 1. หน้าเลือกเมนู (Menu)
- แสดงรายการกาแฟพร้อมราคา
- ลูกค้าเลือกเมนู ระดับความหวาน และจำนวนแก้ว
- กดปุ่ม "ใส่ตะกร้า"

### 2. หน้าตะกร้าสินค้า (Cart)
- สรุปรายการที่เลือก พร้อมราคาต่อรายการ
- แก้ไขจำนวนแก้วได้ (ปุ่ม + / -)
- แสดงยอดรวม และกด "ไปหน้าจัดส่ง"

### 3. หน้ากรอกเบอร์โทร/ที่อยู่จัดส่ง (Delivery)
- กรอกชื่อ เบอร์โทร ที่อยู่จัดส่ง
- กด "ยืนยันสั่งซื้อ" แล้วรับหมายเลขคำสั่งซื้อ

## กฎเกณฑ์ระบบ (Business Rules)

| ลำดับ | กฎ | รายละเอียด |
|---|---|---|
| BR-01 | ยอดสั่งซื้อขั้นต่ำ 100 บาท | ยอดรวมต่ำกว่า 100 บาท ระบบแจ้งเตือนและไม่ให้สั่งซื้อ (เท่ากับ 100 บาทผ่านได้) |
| BR-02 | เบอร์โทรต้องเป็นตัวเลข 10 หลัก | ตัวเลข 0-9 เท่านั้น ขึ้นต้นด้วย 0 ห้ามมีตัวหนังสือ/สัญลักษณ์ |
| BR-03 | ความหวานเริ่มต้น | ถ้าไม่เลือกความหวาน ระบบตั้งเป็น "หวานปกติ 100%" อัตโนมัติ |
| BR-04 | จำนวนแก้วขั้นต่ำ 1 แก้ว | ห้ามใส่ 0 หรือตัวเลขติดลบ ทั้งตอนเลือกเมนูและในตะกร้า |

## รายการเมนูและราคา

| รหัส | เมนู | ราคา |
|---|---|---|
| M01 | อเมริกาโน่ | 40 บาท |
| M02 | ลาเต้ | 45 บาท |
| M03 | โมจิ | 50 บาท |
| M04 | มัทฉะลาเต้ | 55 บาท |

## ตัวอย่างการคำนวณยอด (ใช้เป็น Test Data)

- ลาเต้ 45 x 3 แก้ว = 135 บาท (ผ่านขั้นต่ำ)
- อเมริกาโน่ 40 x 2 = 80 บาท (ไม่ผ่านขั้นต่ำ)
- โมจิ 50 x 2 = 100 บาท (ผ่านพอดี — boundary)
- มัทฉะลาเต้ 55 x 2 = 110 บาท (ผ่านขั้นต่ำ)
