# ตัวอย่างรายงานบั๊ก (Bug Report) — ระบบสั่งกาแฟออนไลน์

รูปแบบ: ชื่อบั๊ก / ขั้นตอน / ผลจริง vs ที่ควรจะเป็น

---

## Bug ที่ 1

**ชื่อบั๊ก (Bug Title):** กรอกเบอร์โทรเป็นตัวหนังสือภาษาไทยได้ ระบบไม่แจ้งเตือน และสั่งซื้อสำเร็จ

**ขั้นตอนที่ทำให้เกิดบั๊ก (Steps to reproduce):**
1. เข้าหน้าเลือกเมนู สั่งลาเต้ 3 แก้ว (135 บาท)
2. ไปหน้ากรอกเบอร์โทร/ที่อยู่จัดส่ง
3. กรอกชื่อ "สมชาย" เบอร์โทร "๐๘๑๒๓๔๕๖๗๘" (เลขไทย) และที่อยู่ครบ
4. กดปุ่มยืนยันสั่งซื้อ

**สิ่งที่เกิดขึ้นจริง (Actual):** ระบบสั่งซื้อสำเร็จ ไม่มีข้อความแจ้งเตือน เบอร์ดังกล่าวถูกบันทึกลงคำสั่งซื้อ ทำให้ร้านติดต่อลูกค้าไม่ได้

**สิ่งที่ควรจะเป็น (Expected):** ระบบแจ้งเตือน "เบอร์โทรต้องเป็นตัวเลข 0-9 ครบ 10 หลัก" และไม่ให้กดยืนยันสั่งซื้อจนกว่าจะกรอกถูกต้อง

**ความรุนแรง (Severity):** High — ร้านติดต่อลูกค้าไม่ได้ กระทบการจัดส่ง

## Bug ที่ 2

**ชื่อบั๊ก (Bug Title):** กดลดจำนวนแก้วเหลือ 0 ระบบคิดเงินยอดติดลบ และสั่งซื้อได้

**ขั้นตอนที่ทำให้เกิดบั๊ก (Steps to reproduce):**
1. เข้าหน้าเลือกเมนู ใส่ลาเต้ 1 แก้ว (45 บาท) ลงตะกร้า
2. เข้าหน้าตะกร้า กดปุ่มลดจำนวน (-) 1 ครั้ง จำนวนเหลือ 0
3. กดปุ่มลดอีก 1 ครั้ง จำนวนขึ้นเป็น -1 ยอดรวมแสดง -45 บาท
4. กดไปหน้าจัดส่ง กรอกข้อมูลครบ แล้วกดยืนยันสั่งซื้อ

**สิ่งที่เกิดขึ้นจริง (Actual):** ยอดรวมเป็น -45 บาท และระบบยังให้ยืนยันสั่งซื้อสำเร็จ (ไม่เข้าเงื่อนไขขั้นต่ำ 100 บาท เพราะยอดติดลบ)

**สิ่งที่ควรจะเป็น (Expected):** ระบบห้ามลดจำนวนต่ำกว่า 1 แก้ว ถ้ากดลบที่ 1 แก้วให้แสดงข้อความยืนยันว่าจะลบรายการออกจากตะกร้าหรือไม่ และยอดรวมต้องไม่ติดลบเด็ดขาด

**ความรุนแรง (Severity):** Critical — คิดเงินผิด เกิดคำสั่งซื้อที่ไม่ควรมีอยู่ได้
